# WEBO

An offline-first anime and manga viewer for Windows and Android. WEBO discovers releases, prepares selected files locally, and provides a focused player, manga reader, download manager, and organized library without hosting media in the cloud.

## Highlights

- Live discovery rails for trending, seasonal, and all-time popular anime.
- Episode and chapter guides with release options shown only after choosing an installment.
- Local on-demand preparation with multi-file selection for seasons, batches, volumes, and chapters.
- Anime playback with audio and subtitle track selection, subtitle styling, progress, resume, and touch-friendly fading controls.
- Manga reading with RTL/LTR modes, fit controls, zoom, bookmarks, adjacent-page preloading, and arrow-key paging.
- A foldered local library organized by title, season, episode, volume, and chapter.
- Download progress, peer and speed telemetry, cache controls, deletion, continuation discovery, settings, diagnostics, and donations.
